# Power Within Collective

Official public website for Power Within Collective and Kim Mittelstadt.

## Stack

- React
- Vite
- React Router
- Cormorant Garamond
- Manrope

## Public Experiences

- Home
- Experiences
- Color Analysis
- Style & Body Analysis
- Makeup Lesson & Direction
- Radiance Reclaimed
- Resources
- Power Within Professional
- Raising Her Confidence Podcast
- Teen Programs
- About Kim
- FAQ
- Contact
- Privacy Policy
- Terms & Conditions

## External Services

Public inquiry, newsletter, and selected resource capture use approved Flodesk destinations configured in src/config/publicLinks.js.

## Development

Install dependencies:
npm.cmd install

Start development:
npm.cmd run dev

## Validation

npm.cmd run lint
npm.cmd run build
npm.cmd run public:check
npm.cmd run test
